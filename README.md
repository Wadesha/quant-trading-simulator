# 量化交易模拟后台（QuantSim）

纯前端的量化交易运营后台模拟器，无需后端与构建。直接用浏览器打开 `index.html` 即可运行，或通过上方 GitHub Pages 链接访问。

## 功能

- **监控总览**：组合总资产、浮动盈亏、年化夏普比率、最大回撤、盈利/亏损账户数
- **平台 / 账户监控**：8 个平台、7 大品类（数字货币 / 股票 / 期货 / 外汇 / 期权 / ETF·基金 / 债券）
- **净值曲线**：SVG 实时绘制组合净值 vs 基准
- **策略操作台（双模式可切换）**
  - 经典操作台：一键式填写全部选项
  - 分步引导操作台：三步上手（① 选平台与品类 → ② 选策略与风控 → ③ 投入资金并执行）
  - 8 种策略、3 档风险杠杆、3 档持仓周期；每次组合都会给出计算结果，并以醒目彩色横幅呈现一句话评价
- **交易 / 决策记录**：每笔模拟自动归档，可清空

## 本地运行

```bash
python3 -m http.server 8123
# 然后打开 http://localhost:8123
```

> 所有数据均为模拟，不构成任何投资建议。
