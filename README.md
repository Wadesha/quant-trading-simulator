# 量化交易模拟后台（QuantSim）

纯前端的量化交易运营后台模拟器，无需后端与构建。直接用浏览器打开 `index.html` 即可运行，或通过上方 GitHub Pages 链接访问。

## 功能

- **驾驶舱（固定在顶部）**：一只大屏式的驾驶舱常驻顶部，展示组合总资产、累计浮盈、已执行笔数、胜率、最大回撤、夏普比率，附一条资产净值走势曲线
- **操作按钮化**：8 个平台、7 大品类（数字货币 / 股票 / 期货 / 外汇 / 期权 / ETF·基金 / 债券）、8 种策略、3 档风险杠杆、3 档持仓周期被打包成一条条「预案」操作，直接做成一排按钮，点一下即执行
- **数据变化高亮**：每点一次按钮，驾驶舱里变化的指标会闪烁高亮并显示 +/− 增量数字，净值曲线同步延伸
- **醒目结果评价**：每次操作都会弹出一个彩色大字横幅，给出一句话评价（大幅盈利 / 稳健盈利 / 小幅亏损 等）
- **操作记录**：每笔模拟自动归档，可清空

## 本地运行

```bash
python3 -m http.server 8123
# 然后打开 http://localhost:8123
```

> 所有数据均为模拟，不构成任何投资建议。
